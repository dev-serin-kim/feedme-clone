# 섹션 골라 담기 · 여러 URL 합치기 · 보노보노 PPT 슬라이드쇼

이미 출시된 URL→Markdown 변환 화면에 세 가지를 더합니다. 필요한 부분만 골라 넘기고, 여러 글을 한 번에 묶어 넘기고, 변환한 글을 보노보노 PPT풍 발표 슬라이드로 띄웁니다.

## 연결된 자료

- [url-to-markdown](../url-to-markdown/spec.md) — 기존 화면의 입력, 변환, 결과, 내보내기 바, 다크 모드 동작을 정합니다. 이 spec은 그 위에 더하는 동작만 다룹니다.
- [visual-direction](../../decisions/visual-direction.md) — 새 UI와 슬라이드쇼의 시각 스타일(보노보노 PPT풍)을 정합니다.
- [ui-composition](../../decisions/ui-composition.md) — shadcn 구성과 상태 설계 원칙을 정합니다.

## 사용자가 얻는 것

- 긴 글에서 필요한 섹션만 골라 복사·다운로드하거나 LLM에 넘깁니다. 줄이면 6,000자 안에 들어가 클립보드 없이 바로 채워 열 수 있습니다.
- 최대 5개 URL을 한 번에 변환해 하나의 Markdown 묶음으로 받고, "이 글들 비교해줘"처럼 한 번에 넘깁니다.
- 변환한 글을 무지개 WordArt 표지와 빽빽한 본문으로 된 보노보노 PPT풍 슬라이드쇼로 띄워 발표하거나 `.html`로 저장합니다.

## 수용 기준

### 여러 URL

- 주소창 아래(예시 링크 위)에 "+ URL 추가" 버튼이 있습니다. 누를 때마다 주소 입력 칸이 하나씩 늘고, 최대 5칸입니다. 5칸이 되면 버튼이 비활성화됩니다.
- 두 번째 칸부터는 칸마다 빼기(X) 버튼이 있습니다. 첫 칸의 지우기(X)는 기존처럼 모든 입력·결과를 지우고 처음 상태로 돌아갑니다. 추가한 칸도 함께 사라집니다.
- 변환하기를 누르면 비어 있지 않은 칸만 변환합니다. 하나라도 http/https 웹 주소가 아니면 아무것도 변환하지 않고, 해당 칸이 오류 표시로 바뀌며 기존 안내 문구가 나옵니다.
- 여러 주소는 동시에 변환하며, 로딩 화면은 기존과 같습니다.
- 일부만 실패하면 성공한 글로 결과를 보여 주고, 결과 위에 경고로 "N개 중 M개를 가져오지 못했어요"와 실패한 주소·이유(가져오지 못함 / 본문 없음)를 보여 줍니다.
- 모두 실패하면 기존 오류 화면을 보여 줍니다. 실패 이유가 모두 "본문 없음"일 때만 "본문을 찾지 못했어요"이고, 그 밖에는 "페이지를 가져오지 못했어요"입니다.
- 결과가 글 하나면 기존 결과 헤더 그대로입니다. 두 개 이상이면 헤더에 "문서 N개 · 총 X자"와 글마다 사이트명·URL·제목 목록이 나오고, 본문은 글마다 제목·출처 머리말과 함께 이어서 보여 줍니다.
- 예시 링크를 누르면 첫 칸에 채워집니다.

### 묶음 문서 (복사·다운로드·LLM·PPT 공통)

- 글이 하나면 기존 형식(`# 제목`, `출처: URL`, 본문) 그대로입니다.
- 글이 여럿이면 글마다 그 형식으로 만든 뒤 `---` 구분선으로 이어 붙입니다.
- 다운로드 파일 이름은 글이 하나면 `{제목}.md`, 여럿이면 `{첫 제목} 외 N개.md`입니다.

### 섹션 골라 담기

- 글마다 본문을 섹션으로 나눕니다. 그 글에서 가장 높은 단계의 제목(`#`~`###` 중 가장 얕은 것)이 섹션 경계이고, 첫 제목 앞의 글은 "도입부" 섹션입니다. 코드 블록 안의 `#` 줄은 제목으로 보지 않습니다.
- 결과 본문에서 섹션마다 제목 앞에 체크박스가 있고, 기본은 모두 선택입니다. 도입부는 "도입부" 라벨의 체크박스를 씁니다.
- 선택을 해제한 섹션은 제목만 흐리게 남고 본문이 접힙니다. 다시 선택하면 펼쳐집니다.
- 결과 헤더의 글자 수는 선택한 섹션 기준이며, 일부만 고르면 "선택 X자 / 전체 Y자"로 보여 줍니다.
- 복사, `.md` 다운로드, ChatGPT·Claude로 열기, PPT로 보기 모두 선택한 섹션만 담습니다. 6,000자 기준도 선택한 내용으로 판단합니다.
- 모든 섹션을 해제하면 내보내기 버튼들이 비활성화됩니다.
- 새로 변환하거나 지우면 선택이 초기화됩니다.

### 보노보노 PPT 슬라이드쇼

- 내보내기 바에 "PPT로 보기" 버튼이 있습니다. 누르면 새 탭에 슬라이드쇼가 열립니다.
- 슬라이드 구성
  - 표지: 무지개 WordArt 제목(글이 여럿이면 "문서 N개 모음"), 사이트명·저자, "발표자: feedme"
  - 글이 여럿이면 글마다 간지 슬라이드(그 글의 제목)
  - 선택한 섹션마다 슬라이드 한 장. 섹션 제목이 슬라이드 제목이고, 본문을 서식(목록·굵게·링크·코드 등)과 함께 빽빽하게 채웁니다. 글이 넘치면 넘치지 않을 때까지 글자를 줄이고(최소 11px), 그래도 넘치면 "(계속)" 슬라이드로 이어 갑니다.
  - 마지막: "감사합니다 ★ 질문 받습니다" WordArt 슬라이드
- 조작: →/Space/클릭은 다음, ←는 이전, F는 전체 화면, 화면 아래에 "현재 / 전체" 번호
- 슬라이드쇼 화면에 ".html 저장" 버튼이 있어 같은 슬라이드쇼를 `{제목}.html`로 내려받습니다. 내려받은 파일은 인터넷 없이 열어도 똑같이 동작합니다.
- 시각 스타일은 무지개 그라데이션 배경, 궁서체 WordArt 제목, 굴림체 본문, 입체 테두리 등 [visual-direction](../../decisions/visual-direction.md)을 따릅니다.

## 정해진 제약과 이유

- **PPT는 브라우저 슬라이드쇼**: `.pptx`는 편집할 수 있지만 무지개 WordArt 같은 장식이 단순해지고 라이브러리가 더 듭니다. 사용자가 밈 감성을 그대로 살리는 브라우저 슬라이드쇼를 골랐습니다.
- **여러 URL은 한 문서로**: 글마다 탭으로 나누면 "비교해줘"처럼 한 번에 넘기기 어렵습니다. 사용자가 합치는 방식을 골랐습니다.
- **섹션 선택은 모든 내보내기에 적용**: 사용자가 골랐습니다. 화면에서 보이는 선택과 나가는 내용이 항상 같아야 헷갈리지 않습니다.
- **최대 5개 URL**: 한 번에 서버 함수를 여러 번 부르므로 상한을 둡니다.

## 가정 (바꿀 수 있음)

- 섹션 선택 상태는 저장하지 않습니다.
- 슬라이드 한 장에 넣는 본문은 약 700자 단위로 나눈 뒤, 넘치면 글자 크기를 줄입니다.
- 슬라이드쇼는 다크 모드와 관계없이 밝은 무지개 테마로 엽니다.
- 첫 화면의 위키 예시 결과도 섹션 선택과 PPT로 보기를 그대로 쓸 수 있습니다.

## 손대지 않는 것

- LLM으로 슬라이드를 요약·재구성하는 기능: 비용과 API 키가 필요해 범위 밖입니다.
- `.pptx` 내보내기: 사용자가 고르지 않았습니다.
- 섹션 순서 바꾸기, 글 순서 바꾸기: 요구에 없습니다.

## 남은 위험

- 섹션 경계를 제목 단계로만 나누므로, 제목이 없는 글은 "도입부" 하나뿐이라 골라 담기 효과가 없습니다.
- 여러 URL을 동시에 가져오므로, 같은 사이트 여러 페이지를 넣으면 그 사이트가 요청을 막을 가능성이 커집니다.
- 저장한 슬라이드쇼의 CSS·스크립트는 파일 안에 있지만, 원문에 있던 이미지는 원래 주소에서 불러오므로 인터넷 없이 열면 이미지만 보이지 않습니다.
- 원문의 각주 표시(예: `[^13]`)는 각주 내용이 다른 슬라이드에 있으면 글자 그대로 보입니다.
- 슬라이드쇼를 새 탭으로 열 때 브라우저 팝업 차단에 걸리면 열리지 않을 수 있습니다.
